# NOTICE — Concept Provenance

Mulqi Context Compression v0.1.0 is an independent, clean-room product. It contains no code,
prompt text, tests, or other copyrighted material from any other project.

The *concepts* implemented here — model-driven incremental hierarchical context compression
("the fold"), tiered restorable digest blocks, growth-gated demand-side triggering, and a
versioned compression doctrine as an executable prompt specification — were studied from the
publicly documented design of the open-source project **billion-context**
(https://github.com/ranxianglei/billion-context), MIT License, © 2026 ranxianglei, including
its published preprint "Model-Driven Incremental Hierarchical Compression: Training-Free
Multi-Generational Context Management for Long-Lived Coding Agents".

Per that license and as a matter of transparent attribution, the concepts above are acknowledged
here. This product's code, documentation, and tooling are original work by Mulqi and are
